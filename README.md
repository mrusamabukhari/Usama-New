# Linen House Export — Instagram $10K/Month Toolkit

A Claude-powered toolkit to grow your Linen House export business on Instagram to $10,000/month.

## Tools Included

| File | Purpose |
|---|---|
| `revenue_calculator.py` | See your monthly projection & action plan |
| `content_generator.py` | Auto-generate captions, hooks, hashtags, DMs |
| `lead_tracker.py` | Track B2B wholesale leads through your pipeline |

## Quick Start

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_key_here

# Step 1: See your roadmap to $10K
python revenue_calculator.py

# Step 2: Generate this week's content
python content_generator.py

# Step 3: Track your wholesale leads
python lead_tracker.py
```
